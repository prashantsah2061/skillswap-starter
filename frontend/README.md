# Frontend

This Next.js application contains all pages, components, styling, local demo fixtures, and public images. It has no backend connection or Supabase proxy.

From the repository root, run `npm ci` and `npm run dev`. Open http://localhost:3000 and choose **Try demo**.

`@/` imports resolve to this application's `src/`. `@shared/` resolves to `../shared/types/`.

See `../docs/FRONTEND-DEMO.md` for page and interaction details.
